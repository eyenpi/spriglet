# Reactive playback validation

Run `./tools/ReactiveValidation/run.sh` on macOS 26 or later with full Xcode
selected. The tool builds the verified schema-3 Acorn candidate in an isolated
bundle, then exercises the production renderer under a real AppKit run loop.

The native checks queue direct petting at an authored alert boundary and during
an airborne hop. They require the exact safe marker frame/root pair before the
renderer follows graph-defined dismiss, abort, or brake routes, and verify that
no animation-state gap, display link, decoded buffer, or rig animation remains
after settling. A lower-priority contextual request cannot displace direct
petting once it is pending. Direct input can also redirect from the retained
start pose before frame zero appears. A held interaction must freeze the exact
committed pair until release, including while frame zero is still decoding. A
character directory with only the legacy manifest also remains playable through
the in-memory package adapter.

The same run loads the shipping behavior policy and character graph through the
application coordinator. Deterministic inputs prove common alert and rare
directional-dodge selection, geometry fallback, execution-only token/cooldown
consumption, and suppression of a current approach after direct interaction.
The JSON report contains semantic outcomes and counts only.

The tool posts no input events, reads no unrelated application content, and
writes generated resources only beneath its ignored `.build` directory.
