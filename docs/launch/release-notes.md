Spriglet brings a little quiet company to your Mac. Meet Sprout: a soft, leaf-eared companion that rests, walks, reacts to petting, and settles beside your work.

This is a **source preview for Apple silicon and macOS 26 or later**. Build it with full Xcode using the [README instructions](https://github.com/eyenpi/spriglet-public#try-the-public-preview). A signed, notarized app download is not included yet.

- One polished character sample, with grounded walks in both directions, local petting, dragging, quiet behavior, and pause/hide controls.
- A native first-run welcome and compact controls, developed with a real GitHub Copilot CLI contribution.
- Editable Blender character, rig, lighting, animation pipeline, and app icon.
- MIT licensing for both code and artwork. No account, analytics, desktop capture, or server.

The attached MP4 and GIF show the exact animation assets and motion data over light and dark backgrounds. They are animation asset demos, not desktop recordings.

Debug/Release builds, Swift tests, asset/contact checks, and the current app runtime probe pass. The clean public export records pixel-preserving metadata removal and fresh model/icon readback. See the [release verification and known limits](https://github.com/eyenpi/spriglet-public/blob/codex/public-preview/docs/public-preview.md) for the evidence and remaining work.

The full animation library, wider desktop compatibility testing, sustained battery profiling, and signed distribution are still ahead.
