# Spriglet app icon

The public preview uses the supported macOS `AppIcon.appiconset` pipeline in `Sources/Spriglet/Assets.xcassets`. The icon is a near-frontal portrait of the existing Sprout model: the same face, leaf ears, olive fur, and cream markings, framed for recognition at small sizes. A simple warm background keeps the face prominent. The lower body is cropped by the camera; the source model is intact.

## Current Apple workflow

Apple currently supports app icons supplied through either Icon Composer or an asset catalog. Its asset-catalog documentation requires an image for each macOS size. This catalog supplies 16, 32, 128, 256, and 512 points at both 1× and 2×, including the 1024-pixel App Store image. See [Configuring your app icon using an asset catalog](https://developer.apple.com/documentation/xcode/configuring-your-app-icon) and [App Store Connect: Add an app icon](https://developer.apple.com/help/app-store-connect/manage-app-information/add-an-app-icon).

The master is an opaque, unmasked square in sRGB, with centered identifying features and no baked outer shadow. Apple’s current [app icon guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons) favors simple, recognizable designs and system masking. Apple also explains how macOS 26 masks or adjusts existing Mac icons in [Say hello to the new look of app icons](https://developer.apple.com/videos/play/wwdc2025/220/). Native system appearance should be reviewed after integrating the catalog; a raw PNG preview does not show those system treatments.

Icon Composer is an optional future authoring path. Xcode 26.6 includes Icon Composer 1.6 and its `ictool` exporter. The installed CLI documents export of an existing `.icon` document; Apple documents document creation and layer import through the app. The first-launch agreement was left unaccepted, and this preview uses the supported catalog path. A transparent portrait layer is retained for future composition. A `.icon` document would replace the catalog icon as Xcode's primary source; this release does not claim authored Liquid Glass, dark, or mono variants. See [Creating your app icon using Icon Composer](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer).

## Editable source and rebuild

`art/sprout/public-preview/spriglet-icon.blend` is the derived editable icon scene. Its source is `art/sprout/sample-v01/sprout-sample-v01.blend`, whose SHA-256 is checked before and after export. The icon render does not save or alter the source model, its Actions, runtime PNGs, or historical review files. The new scene retains the native armature and surface-bound Curves groom.

Run from the repository root:

```sh
BLENDER_USER_RESOURCES="$PWD/.build/art/sprout-icon/runtime" /Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python art/sprout/public-preview/render_icon.py -- --resolution 1024 --samples 128 --device METAL
sh art/sprout/public-preview/export_icon_catalog.sh
BLENDER_USER_RESOURCES="$PWD/.build/art/sprout-icon/runtime" /Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python art/sprout/public-preview/verify_icon.py
```

The renderer uses Blender 5.2.1 LTS and the installed Metal device. Use `--device CPU` for an explicit CPU fallback. It does not save Blender preferences. Existing studio lighting and character materials are preserved; the floor is hidden and a separate emissive plane supplies the icon background. The saved compositor denoises color while preserving render alpha. The image is rendered from editable geometry; it is not retouched or generated by an image model.

`export_icon_catalog.sh` uses the installed `sips --resampleHeightWidth` command to produce the ten PNG sizes. `icon-render.json` records source/render hashes and settings. `icon-verification.json` records each file's size, decoded alpha, color space, and hash, plus an independent `actool` compile for macOS 26.0. The verifier creates temporary compiled output in the ignored `.build` directory and never renders or saves a model.

## Xcode integration

Include `Sources/Spriglet/Assets.xcassets` in the app target's resources and set `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`. Xcode's asset compiler supplies `CFBundleIconName` and the compatible icon resource entry; no app code or runtime icon assignment is needed.

Verified tooling: Xcode 26.6 build 17F113, asset compiler 26.6 build 24765, and Blender 5.2.1 LTS build 9e2066aef7ef. The current catalog compiles with no warnings or errors. Visual inspection covered the master and 32-/64-pixel variants; final Dock/Finder appearance is a separate native app check.
